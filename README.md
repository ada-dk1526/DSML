## 📚 Course Overview and Learning Outcomes
Welcome to the Data Science and Machine Learning for Planet Earth module! This course covers essential concepts in data science, including working in a computational notebook environment, data preparation and pipelines, and various machine learning algorithms for regression, classification, clustering, and time series.

### Learning Outcomes:
- Implement the different steps involved in a data science / machine learning project, from initial data exploration to the development of reproducible data preparation and modelling pipelines.
- Clean and manipulate different types of data and prepare them for machine learning analysis using open-source libraries.
- Select an appropriate machine learning algorithm for the problem at hand and optimise predictive performance by tuning hyperparameters and applying suitable validation strategies.
- Evaluate the performance of a machine learning pipeline through appropriate performance metrics, and interpret model outputs using feature-importance and explanation techniques.
